# Velo — Speak. It flows.

Active product branding, based on the supplied Velo mockup.

- AppIcon.png: generated app icon master; AppIcon.iconset: macOS sizes.
- Velo-Logo.png: generated horizontal wordmark and tagline.
- MenuBar-*.png: native template wave mark at small and Retina sizes.
- export-menu.swift: reproducible menu-bar mark export.

Built-in image generation prompts:
1. Standalone macOS app icon, smooth cyan-blue-violet-pink flowing wave matching the reference, asymmetric tall left crest, deep central trough and smaller right crest, on pearl white rounded square; no text; transparent outside tile.
2. Horizontal Velo lockup matching the reference, flowing gradient wave left, black geometric Velo right, spaced SPEAK. IT FLOWS. tagline below; white background, no mockup panels.

The menu-bar silhouette is a simplified native path for crisp template rendering.
